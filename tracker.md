# Трекер задач

Источник требований — `REQUIREMENTS.md`. Этот файл только отслеживает статус.

## Правила

- Статус может быть `todo`, `done` или `blocked`. Других значений нет.
- Ставить `done` можно, только когда `verify.ps1` зелёный и поведение задачи покрыто тестами.
- Если задача не поддаётся: поставить `blocked`, создать файл `BLOCKED` в корне репозитория
  и записать в него причину. Прогон после этого останавливается.
- Статус меняет тот, кто делает задачу. Файл — часть изменения, он коммитится вместе с кодом.
