# Змейка

Классическая «Змейка» для Windows на WPF (.NET 10).

- `src/Snake.Core` — правила игры. Не знает про WPF.
- `src/Snake.Wpf` — интерфейс: отрисовка, ввод, таймер тиков.
- `tests/Snake.Core.Tests` — тесты правил и хранилища.

Требования описаны в `REQUIREMENTS.md`, статус задач — в `tracker.md`.

## Что нужно

- Windows 10 или 11.
- [.NET SDK 10](https://dotnet.microsoft.com/download) (проверено на 10.0.204).

Проверить версию:

```powershell
dotnet --version
```

## Собрать

```powershell
dotnet build Snake.slnx -c Release
```

Собрать только приложение:

```powershell
dotnet build src/Snake.Wpf/Snake.Wpf.csproj -c Release
```

Предупреждения компилятора приравнены к ошибкам, поэтому сборка либо чистая, либо падает.

## Запустить

```powershell
dotnet run --project src/Snake.Wpf/Snake.Wpf.csproj -c Release
```

Или запустить собранный файл:

```powershell
.\src\Snake.Wpf\bin\Release\net10.0-windows\Snake.Wpf.exe
```

При первом запуске приложение спросит имя игрока, потом покажет главное меню.

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки или WASD | Направление |
| Space или P | Пауза / продолжить |
| Enter | Новая партия на экране конца игры |
| Esc | Выход в меню |
| Tab и стрелки | Переход между элементами меню |

Мышь не нужна ни на одном экране. Игра сама встаёт на паузу, когда окно теряет фокус.

## Уровни сложности

| Уровень | Интервал тика | Множитель очков | Край поля |
|---|---|---|---|
| Лёгкий | 200 мс | ×1 | проход сквозь стену |
| Обычный | 130 мс | ×2 | смерть |
| Сложный | 90 мс | ×3 | смерть |

Граница поля нарисована по-разному: сплошная рамка, если стена убивает, и пунктирная,
если разрешён проход сквозь стену.

## Где лежат данные

Рекорды и настройки хранятся в `%APPDATA%\Snake\`:

- `highscores.json` — таблица рекордов, отдельно по каждому уровню сложности;
- `settings.json` — имя игрока и последняя выбранная сложность.

Папка создаётся при первом сохранении. Если файл испорчен или удалён, приложение
запускается со значениями по умолчанию.

## Тесты и проверка

Только тесты:

```powershell
dotnet test tests/Snake.Core.Tests/Snake.Core.Tests.csproj -c Release
```

Полная машинная проверка Definition of Done (сборка, зависимости `Snake.Core`,
тесты, покрытие, статус задач в `tracker.md`):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./verify.ps1 -Stage 0 -MinTests 40
```

Код выхода 0 означает, что машинная часть DoD выполнена. Ручные сценарии приёмки
перечислены в разделе 7.3 файла `REQUIREMENTS.md`.
